🚀 How to Start the Application

Step 1: Install Dependencies (if not already done)

cd "d:\EDUAI perfomance predictor"
pip install -r requirements.txt

Step 2: Start the Flask Server

Choose one of these methods:

Method A: Using Python directly
cd "d:\EDUAI perfomance predictor"
python app.py
Method B: Using the batch file
Double-click run_app.bat in the project folder
Method C: Using PowerShell
cd "d:\EDUAI perfomance predictor"
.\run_app.ps1

🌐 Access the Application

Once the Flask server is running, open your web browser and go to:

http://localhost:5000

The application will display a form with 19 fields for student information. Fill in all the required data and click "Predict Student Performance" to get predictions.

📋 Required Input Fields

The model requires these 19 student factors:

  • Hours Studied per Week (0-10)
  • Attendance Percentage (0-100)
  • Parental Involvement (Low/Medium/High)
  • Access to Resources (Low/Medium/High)
  • Extracurricular Activities (Yes/No)
  • Sleep Hours per Night (0-12)
  • Previous Scores (0-100)
  • Motivation Level (Low/Medium/High)
  • Internet Access (Yes/No)
  • Tutoring Sessions per Month (0-8)
  • Family Income Level (Low/Medium/High)
  • Teacher Quality (Low/Medium/High)
  • School Type (Public/Private)
  • Peer Influence (Negative/Neutral/Positive)
  • Physical Activity hours/week (0-10)
  • Learning Disabilities (Yes/No)
  • Parental Education Level (Low/Medium/High)
  • Distance from Home (Near/Moderate/Far)
  • Gender (Male/Female)

🔍 Troubleshooting

If you get "Network Error" message:

This means the Flask server is not running. Make sure to start it using one of the methods above.

If the page doesn't load:

Check that the Flask server started successfully and is running on port 5000.

If you get import errors:

Run: pip install -r requirements.txt
